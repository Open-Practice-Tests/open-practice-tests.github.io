upstream license comments retained. Practice Studio supplies a local integration
for PDF text extraction and image rendering. Downloaded tests do not need PDF.js.

included as separate runtime libraries in the release. Their own licenses apply
when installed. The public release uses system fonts, with no remote font assets.
