Question 2

  • Guide question E4.2

Solve 3x + 1 = 2.

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

12

Require x ≠ −1. Multiply 3/(x + 1) = 2 by the nonzero denominator:

3 = 2(x + 1), 1 = 2x, x = 12.

Check in the original: 3/(3/2) = 2. The candidate is not excluded, so it is valid. Review 4.04.

Question 3

  • Guide question E4.3

Solve x + 2 = x − 4 over the real numbers.

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

7

Because x + 2 is nonnegative, the right side x − 4 must be nonnegative; therefore x ≥ 4. Squaring gives

x + 2 = (x − 4)2 x2 − 9x + 14 = (x − 7)(x − 2) = 0.

The candidate 2 fails x ≥ 4. The candidate 7 works: 9 = 3 = 7 − 4. The only solution is 7. Review 4.08.

Question 5

  • Guide question E4.5

How many real solutions does 2x − 1x − 3 = 5x − 3 have?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

No solution

The original denominator excludes x = 3. Clearing that denominator gives 2x − 1 = 5, hence x = 3. This is the only candidate, and it is forbidden. It cannot become a solution merely because the transformed linear equation accepts it. Review 4.05.

Guide question E4.1

Simplify x2 − 25x − 5 and state the original restriction.

Show model answerHide model answer for question E4.1

x + 5, with x ≠ 5

Factor the numerator and preserve the denominator restriction:

x2 − 25x − 5 = (x − 5)(x + 5)x − 5 = x + 5, x ≠ 5.

The simplified formula has the same outputs as the original at every allowed input, but the original still has no value at 5. Review 4.02.

Guide question E4.4

Solve |3x − 2| = 10 over the real numbers.

Show model answerHide model answer for question E4.4

4 and −83

Split |3x − 2| = 10 into the two legitimate branches:

3x − 2 = 10 or 3x − 2 = −10.

These give x = 4 and x = −8/3. Substituting either makes the expression inside the absolute value 10 or −10, whose absolute value is 10. Review 4.10.
