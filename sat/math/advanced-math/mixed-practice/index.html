Advanced Math: mixed practice

42 questions in random order. There is no built-in timer or score. Choose or enter an answer, then press Show solution to see how you did and why. Reloading starts a fresh, shuffled session.

Work through the set before checking solutions. Guide question labels match the source lesson references.

Work independently. These three sets deliberately mix the seven sections. Each contains 14 questions: two from each section, presented without topic labels. They are focused Advanced Math practice, not simulations of a full adaptive SAT Math module. The sets are not calibrated to predict a score.

For a first attempt, work without a time limit and explain your decisions on scratch paper. On a later attempt, track time as well as accuracy. A calculator is permitted, but it is not always the fastest method. For a question without answer choices, enter a single number. Give an exact fraction when appropriate; no question here requires an irrational numeric entry.

Question 1

  • Guide question M01

Which expression is equivalent to (3x + 2)(x − 4)?

Why this answer

B: 3x2 − 10x − 8

Distribute both terms: (3x + 2)(x − 4) = 3x2 − 12x + 2x − 8 = 3x2 − 10x − 8.

The middle coefficient comes from two products, not one. A fast check at x = 0 gives −8, eliminating choices with the wrong constant, but it does not distinguish all remaining choices. Check at a second convenient input or complete the expansion. Review 1.02.

Question 2

  • Guide question M02

The function f is defined by f(x) = −3(x − 2)2 + 12. What is the maximum value of f?

Why this answer

C: 12 The expression is already in vertex form. Since (x − 2)2 ≥ 0, multiplying by −3 makes that term nonpositive. Therefore −3(x − 2)2 + 12 ≤ 12, with equality at x = 2. The maximum output is 12. The numbers 2 and −3 are respectively the vertex input and vertical-scale coefficient; neither is the requested value. Review 3.06.

Question 3

  • Guide question M03

A model gives Q(t) = 500(0.8)t/2, where t ≥ 0. What is the value of Q(6)?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

256

Substitute t = 6 into the whole exponent:

Q(6) = 500(0.8)6/2 = 500(0.8)3 = 500(0.512) = 256.

There are three 2-unit decay periods, each retaining 80% of the preceding amount. Applying the factor six times would use the wrong time interval. Estimation also helps: the result should be positive and below 500, but well above 500(0.8)6. Review 5.03.

Question 4

  • Guide question M04

For a > 0, which expression is equivalent to a5/6a1/3?

Why this answer

D: a

The positive-base assumption makes rational exponent rules straightforward. Divide powers with the same base by subtracting exponents:

a5/6a1/3 = a5/6−2/6 = a3/6 = a1/2 = a.

Do not divide the exponents; their difference is required by the quotient rule. Also, the rule is not an instruction to subtract the actual numerator and denominator. Review 2.09.

Question 5

  • Guide question M05

What is the solution to 4x + 1 = 7?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

12

Both sides of 4x + 1 = 7 are nonnegative. Square, solve, and verify:

4x + 1 = 49, 4x = 48, x = 12.

The original radicand is 49, so 49 = 7 as required. Squaring creates candidate solutions; substitution confirms this one. There is no extra negative branch for the value of the principal square root itself. Review 4.07.

Question 6

  • Guide question M06

The point (2, −3) lies on the graph of y = f(x). If g(x) = f(x + 4) + 5, which point must lie on the graph of y = g(x)?

Why this answer

A: (−2, 2)

The given point means f(2) = −3. To use that known output in g(x) = f(x + 4) + 5, make the inside input equal 2: x + 4 = 2 x = −2.

Then g(−2) = f(2) + 5 = −3 + 5 = 2. Thus the new point is (−2, 2). Solving the inside equation avoids the common sign error of shifting right when the formula contains x + 4. Review 6.05.

Question 7

  • Guide question M07

The graphs of y = x2 and y = 3x + 4 intersect at two points. What is the y-coordinate of the intersection whose x-coordinate is positive?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

16

At an intersection, x2 = 3x + 4. Rearrange and factor:

x2 − 3x − 4 = (x − 4)(x + 1) = 0.

The inputs are 4 and −1. The question selects the positive input and asks for its y-coordinate. Thus y = 42 = 16. Check the other equation: 3(4) + 4 = 16. Entering 4 would solve the intermediate equation but answer the wrong question. Review 7.01.

Question 8

  • Guide question M08

Which expression is equivalent to 12x2 − 27?

Why this answer

B: 3(2x − 3)(2x + 3)

Remove the greatest common factor, then factor the difference of squares:

12x2 − 27 = 3(4x2 − 9) = 3((2x)2 − 32) = 3(2x − 3)(2x + 3).

A repeated factor would produce a nonzero linear term. Multiplying conjugates cancels the cross terms, matching the absence of an x term in the original polynomial. Review 1.03 and 1.04.

Question 9

  • Guide question M09

A quadratic function f has zeros −1 and 5, and f(0) = −10. Which equation defines f?

Why this answer

D: f(x) = 2(x + 1)(x − 5)

The zeros determine factors x + 1 and x − 5, but not the leading coefficient. Write f(x) = a(x + 1)(x − 5) and use the given output: −10 = f(0) = a(1)(−5) = −5a, a = 2.

The resulting function has both required zeros and the correct y-intercept. An answer with the right roots but the wrong scale is not enough. Review 3.08.

Question 10

  • Guide question M10

What is the solution to x2 − 4x − 2 = 0?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

−2

Record x ≠ 2 before factoring. The numerator is (x−2)(x+2). A rational expression is zero when its numerator is zero and its denominator is nonzero. The numerator candidates are 2 and −2, but 2 is excluded. At −2, the denominator is −4 and the numerator is zero, so the quotient is zero. Equivalently, simplify to x + 2 while retaining x ≠ 2. Review 4.02.

Question 11

  • Guide question M11

What is the value of (127)−2/3?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

9

A negative exponent takes a reciprocal:

(127)−2/3 = 272/3 = (273)2 = 32 = 9.

The negative sign in the exponent does not turn the output negative. An alternative common-base route is (3−3)−2/3 = 32. Both methods are valid because the base is positive. Review 2.03.

Question 13

  • Guide question M13

The function f is defined by f(x) = x − 5 + 2. What is the smallest real number in its domain?

Why this answer

A: 5

Real square-root outputs require x − 5 ≥ 0, so x ≥ 5. The endpoint x = 5 is allowed and gives f(5) = 2. Thus the smallest input in the domain is 5. The outside +2 changes output values, not the square root’s input restriction. Confusing the minimum output 2 with the smallest allowed input 5 produces a plausible distractor. Review 6.09.

Question 14

  • Guide question M14

Which ordered pair is a solution to the system x2 + y2 = 13 and y = x + 1?

Why this answer

D: (2, 3)

Testing choices is efficient because the target is a single offered pair. For (2, 3),

22 + 32 = 4 + 9 = 13, 3 = 2 + 1.

Both equations hold. The other listed pairs all satisfy the circle equation but fail the line equation. A system requires simultaneous truth, so checking only the easier equation is insufficient. Algebraically, substitution gives 2x2 + 2x − 12 = 0, with intersections (2, 3) and (−3, −2); only the first is listed. Review 7.06.

Question 15

  • Guide question M15

What is the greater of the two solutions to |3x + 2| = 11?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

3

Absolute value equal to a positive constant gives two branches:

3x + 2 = 11 or 3x + 2 = −11.

These yield x = 3 and x = −13/3. The greater solution is 3. Both are valid because their inside expressions have magnitude 11. The question asks for one selected solution, so entering both would not follow the target. Review 4.10.

Question 16

  • Guide question M16

For all real numbers x, (2x + a)(x − 3) = 2x2 + bx − 12, where a and b are constants. What is a + b?

Why this answer

B: 2

Expand the left side: (2x + a)(x − 3) = 2x2 + (a − 6)x − 3a.

The constant identity gives −3a = −12, so a = 4. The linear coefficient is then b = a − 6 = −2. Therefore a + b = 4 − 2 = 2. Comparing only the leading coefficient provides no new information because it is already 2 on both sides. Review 1.11.

Question 17

  • Guide question M17

The function f(t) = Abt, where A > 0 and b > 0, satisfies f(1) = 10 and f(4) = 80. What is f(0)?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

5

The two given inputs are three units apart. Dividing the model values cancels the initial coefficient:

f(4)f(1) = b3 = 8010 = 8.

Because b > 0, b = 2. Then 10 = Ab gives A = 5. Finally, f(0) = Ab0 = A = 5. A factor of 8 belongs to the whole three-unit interval, not to a single unit. Review 5.06.

Question 18

  • Guide question M18

The function f is defined by f(x) = 3x2 − 18x + 20. What is its minimum value?

Why this answer

C: −7

Complete the square, keeping the leading coefficient outside the adjusted square:

3x2 − 18x + 20 = 3(x2 − 6x) + 20 = 3(x − 3)2 − 27 + 20 = 3(x − 3)2 − 7.

The squared term is nonnegative, so the minimum output is −7, achieved at x = 3. The vertex formula also gives x = −(−18)/(2 ⋅ 3) = 3, after which substitution gives −7. Review 3.07.

Question 19

  • Guide question M19

What is the solution to 25x+1 = 125x−1?

Why this answer

A: 5

Use the common positive base 5:

25x+1 = 52x+2, 125x−1 = 53x−3.

Since powers of base 5 are one-to-one, 2x + 2 = 3x − 3, so x = 5. Check the exponents: both sides equal 512. Equating x + 1 and x − 1 directly would ignore the different original bases. Review 2.10 and 5.04.

Question 20

  • Guide question M20

The function f satisfies f(6) = 4. If g(x) = −3f(x/2) + 1, which point must lie on the graph of y = g(x)?

Why this answer

D: (12, −11)

Use the known value f(6) = 4. The inside input in g equals 6 when x/2 = 6, so the new input is 12. The new output is −3(4) + 1 = −11. Therefore g(12) = −11. The factor 1/2 inside the function stretches horizontal distances by 2; it does not halve the point’s input. Review 6.07.

Question 21

  • Guide question M21

The system y = x2 and y = 6x + k has exactly one solution, where k is a real constant. What is k?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

−9

Set the equations equal and collect terms:

x2 = 6x + k x2 − 6x − k = 0.

The leading coefficient is always nonzero, so one intersection requires D = 36 + 4k = 0, giving k = −9. The equation becomes (x − 3)2 = 0, and the point is (3, 9). The number of distinct roots, not their multiplicity, determines the number of intersections here. Review 7.12.

Question 22

  • Guide question M22

For t ≥ 0, an amount is modeled by Q(t) = 40 + 100(0.9)t. Which statement correctly describes this model?

Why this answer

B: the amount above 40 decreases by 10% per unit

Subtract the baseline: Q(t) − 40 = 100(0.9)t.

Therefore Q(t + 1) − 40 = 0.9[Q(t) − 40]. The excess above 40, not the entire amount, is multiplied by 0.9. For example, Q(0) = 140 and Q(1) = 130; that is not a 10% decrease of 140. The excess remains positive for finite t, so the model does not reach exactly 40 at t = 10. Review 5.14.

Question 23

  • Guide question M23

The polynomial P(x) = x3 + ax − 10 has x − 2 as a factor. What is the remainder when P(x) is divided by x + 1?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

−12

The factor condition gives P(2) = 0: 8 + 2a − 10 = 0, a = 1.

Division by x + 1 = x − (−1) leaves remainder P(−1), so

P(−1) = (−1)3 + (−1) − 10 = −12.

Use −1, not 1, in the remainder evaluation. The factor condition and the requested divisor involve different inputs and different purposes. Review 1.12.

Question 24

  • Guide question M24

Which statement describes the solutions to 2x − 3 = x − 1x − 3?

Why this answer

C: no solution

The original equation requires x ≠ 3. On this allowed domain, multiplication by x − 3 gives 2 = x − 1, hence the only candidate is x = 3. It is excluded, so there is no solution. Neither original fraction has a value there. This is a contradiction on the original domain, even though the cleared linear equation by itself has a solution. Review 4.05.

Question 25

  • Guide question M25

The numbers r and s are the roots of 4x2 − 12x + 5 = 0. What is r2 + s2?

Why this answer

B: 132

From the quadratic coefficients,

r + s = 124 = 3, rs = 54.

Then r2 + s2 = (r + s)2 − 2rs = 9 − 5/2 = 13/2. The product enters with a factor of 2 because expanding (r + s)2 creates two cross terms. Finding the individual roots is possible but unnecessary. Review 3.13.

Question 26

  • Guide question M26

The function f(x) = 2 − (x − 1)2 has domain [−1, 4]. What is its range?

Why this answer

A: [−7, 2] The vertex of 2 − (x − 1)2 is (1, 2), and its input lies in [−1, 4], so the maximum is 2. At the endpoints,

f(−1) = 2 − 4 = −2, f(4) = 2 − 9 = −7.

The minimum is −7. The continuous quadratic takes every value between these extremes, so the range is [−7, 2]. The unrestricted range (−∞, 2] ignores the stated domain. Review 6.10.

Question 27

  • Guide question M27

If 9t = 4, what is the value of 272t?

Why this answer

D: 64

Rewrite the target as a power of the given quantity:

272t = 36t = (32t)3 = (9t)3 = 43 = 64.

There is no need to determine t. The key is matching the target exponent to a multiple of the known exponent. Treating the ratio of the bases, 27/9 = 3, as an output multiplier would not respect exponentiation. Review 2.12.

Question 28

  • Guide question M28

Two real numbers satisfy x + y = 10 and x2 + y2 = 58. What is xy?

Why this answer

C: 21

Square the sum and use the given sum of squares:

(x + y)2 = x2 + y2 + 2xy, 100 = 58 + 2xy.

Thus 2xy = 42 and xy = 21. Solving separately for x and y would add work without changing the target. As a check, the pair 3, 7 has sum 10, squared sum 58, and product 21. Review 7.15 and 1.13.

Question 29

  • Guide question M29

For exactly two values of the real constant k, the equation kx2 − 6x + 3 = 0 has exactly one distinct real solution. What is the sum of those two values of k?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

3

When k = 0, the equation is linear: −6x + 3 = 0, with one solution. For k ≠ 0, one distinct real root requires

D = (−6)2 − 4(k)(3) = 36 − 12k = 0, k = 3.

At k = 3, the equation is 3(x − 1)2 = 0. The qualifying parameters are 0 and 3, whose sum is 3. Check the degree before using a quadratic-only criterion. Review 3.15.

Question 30

  • Guide question M30

For every real number z, which expression is equivalent to 18z4?

Why this answer

A: 3z22

Extract the perfect square: 18z4 = 32(z2)2 = 32 |z2| = 3z22.

Because z2 ≥ 0 for every real z, |z2| = z2. Absolute value is essential in the general rule u2 = |u|, but here the quantity being squared is already nonnegative. The other options have the wrong coefficient or power. Review 2.07.

Question 31

  • Guide question M31

The function f(t) = Abt, where A > 0 and b > 0, satisfies f(t + 3) = 7f(t) for all real t. What is f(t + 5)f(t)?

Why this answer

B: 75/3 For a pure exponential, a change of h input units multiplies the output by bh. The condition f(t + 3) = 7f(t) gives b3 = 7, so b = 71/3 since b > 0. Therefore

f(t + 5)f(t) = b5 = 75/3.

The exponent is the desired five-unit interval divided by the known three-unit interval. A linear proportional adjustment of the multiplier would be incorrect. Review 5.12.

Question 32

  • Guide question M32

What is the solution to 3x + 4 = x − 2?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

7

The nonnegative square root requires x − 2 ≥ 0, so x ≥ 2. Squaring gives

3x + 4 = (x − 2)2 = x2 − 4x + 4, x(x − 7) = 0.

The candidates are 0 and 7. Reject 0 because it would make the right side negative. At 7, 25 = 5 = 7 − 2. Squaring alone loses sign information, which the original restriction restores. Review 4.08.

Question 33

  • Guide question M33

Which expression is equivalent to x4 − 13x2 + 36?

Why this answer

C: (x − 2)(x + 2)(x − 3)(x + 3) Temporarily treat x2 as one object. The quadratic pattern is

x4 − 13x2 + 36 = (x2 − 4)(x2 − 9).

Each factor is a difference of squares, giving (x−2)(x+2)(x−3)(x+3). Check the middle term before finishing: −4x2−9x2 = −13x2. The square roots of 4 and 9, not the numbers 4 and 9 themselves, produce the linear factors. Review 1.15.

Question 34

  • Guide question M34

The graph of the quadratic function f is shown. If g(x) = f(x − 1) − 4, what is the vertex of the graph of g?

Why this answer

A: (−1, −1)

Read the original vertex as (−2, 3). In g(x) = f(x − 1) − 4, the inside change shifts the graph right 1, and the outside change shifts it down 4. Thus the vertex becomes

(−2 + 1, 3 − 4) = (−1, −1).

No scale change or reflection occurs, so a vertex maps to a vertex. The labeled point (0, 11) is consistent with the graph but is not needed for this target. Review 6.05.

Question 35

  • Guide question M35

For exactly two real values of k, the system y = x2 + 3x and y = (k + 1)x2 − x + 4 has exactly one solution. What is the sum of those two values of k?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

1

Equating the outputs and collecting terms gives

x2 + 3x = (k + 1)x2 − x + 4 kx2 − 4x + 4 = 0.

At k = 0, this is a linear equation with one solution. At k ≠ 0, one solution requires 16 − 16k = 0, so k = 1. Each valid x determines exactly one y in the original functions. The two parameter values sum to 1. Notice that the difference can become linear even when both original rules remain quadratic. Review 7.13.

Question 36

  • Guide question M36

The identity (x + a)2 − (x + b)2 = 8x + 24 holds for every real number x. What is ab?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

5

Use a difference of squares, or expand just enough to compare coefficients:

(x + a)2 − (x + b)2 = 2(a − b)x + (a2 − b2).

Hence a − b = 4 and (a − b)(a + b) = 24, so a + b = 6. Solving gives a = 5 and b = 1, therefore ab = 5. An equally direct target identity is ab = [(a + b)2 − (a − b)2]/4 = (36 − 16)/4 = 5. Review 1.11 and 1.13.

Question 37

  • Guide question M37

An amount is modeled by f(t) = 300(0.81)t/2, where t is measured in years. By what percentage does the amount decrease each year?

Why this answer

D: 10%

The base 0.81 is the multiplier for a two-year interval. Rewrite the model with exponent t:

300(0.81)t/2 = 300 (0.81)t = 300(0.9)t.

The amount retains 90% each year, so it decreases by 10% per year. A 19% decrease applies over two years; dividing 19 by 2 would not account for compounding. Review 5.07.

Question 38

  • Guide question M38

A quadratic function is defined by f(x) = a(x − 2)(x − 8), where a > 0. Its minimum value is −27. What is f(0)?

Why this answer

A: 48

The roots 2 and 8 are symmetric around the vertex input 5. Evaluate the factored rule at that midpoint:

f(5) = a(5 − 2)(5 − 8) = −9a = −27, a = 3.

Then f(0) = 3(−2)(−8) = 48. Because a > 0, the vertex output is indeed the minimum. The minimum itself is not the requested y-intercept. Review 3.08.

Question 39

  • Guide question M39

If 2x = 3 and 3y = 4, what is 2xy?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

4

Recognize the product exponent as a power of a power. The bases are positive, so the real-exponent rule applies:

2xy = (2x)y = 3y = 4.

The supplied relationships already form a substitution chain. Solving for either exponent separately is unnecessary. This is a useful reminder that a problem containing unknown exponents may ask for a quantity determined without calculating those exponents. Review 2.12 and 2.15.

Question 40

  • Guide question M40

The function f is defined by f(x) = x2 + 2x − 15x2 − 9. Which statement about its graph is true?

Why this answer

D: a hole at (3, 43)

Factor before classifying excluded inputs:

f(x) = (x + 5)(x − 3)(x − 3)(x + 3) = x + 5x + 3, x ≠ 3, −3.

The canceled factor creates a missing point at x = 3. The reduced rule gives its would-be output (3+5)/(3+3) = 4/3. The uncanceled denominator factor produces a vertical asymptote at x = −3, not at 3. Neither excluded input is an x-intercept. Review 4.02.

Question 41

  • Guide question M41

The quadratic function f(x) = ax2 + bx + c, where a > 0, satisfies f(−1) = f(5) = 17. Its minimum value is −1. What is f(0)?

Why this answer

B: 7

Equal outputs at x = −1 and x = 5 locate the quadratic’s axis halfway between them: h = 2. Since the minimum is −1, write f(x) = a(x − 2)2 − 1. Use f(−1) = 17:

17 = 9a − 1, a = 2.

Therefore f(0) = 2(0 − 2)2 − 1 = 7. The symmetry conclusion uses the stated quadratic model with a nonzero leading coefficient; equal outputs in an arbitrary function would not establish this form. Review 6.15.

Question 42

  • Guide question M42

The graphs of y = x2 − 4x + 10 and y = 2x + c intersect at exactly one point (x, y). What is x + y at that point?

Why this answer

C: 10

At an intersection, x2 − 4x + 10 = 2x + c x2 − 6x + 10 − c = 0.

Exactly one point requires D = 36 − 4(10 − c) = 4c − 4 = 0, giving c = 1. The repeated root is x = 6/2 = 3, and y = 2(3) + 1 = 7. Hence x + y = 10. The parameter, input, output, and requested sum are four different quantities; keep them labeled. Review 7.03 and 7.12.
