Question

  • Guide question E5.1

If 8x + 12 = 44, find 2x + 3 without first finding x.

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

11.

The requested expression is one-fourth of the entire left side. Divide the equation by 4 to obtain 2x + 3 = 11. This direct relationship is shorter than solving for x = 4 and substituting, although that route confirms the result. Review Example 5.02.

Question

  • Guide question E5.4

For nonnegative integers n, let Q(n) = 300(1.1)n. What is the least n for which Q(n) > 450?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

5.

Q(4) = 439.23 < 450 and Q(5) = 483.153 > 450. Because the multiplier 1.1 exceeds 1, Q increases with n, so 5 is the first qualifying integer. A graph can locate the crossing, but neighboring integer checks establish the answer exactly relative to the inequality. Review Example 5.10.

Guide question E5.2

If 4x + y = 19 and x + 4y = 16, what is x + y? Explain a method that avoids a graph.

Show model answerHide model answer for question E5.2

7.

Add the equations: 5x + 5y = 35, so x + y = 7. The individual values x = 4 and y = 3 verify the sum and both original equations. The efficient method depends on the target; a different requested expression might favor another combination. Review Example 5.03.

Guide question E5.3

For which real values of a does ax2 + 4x + 4 = 0 have exactly one distinct real solution?

Show model answerHide model answer for question E5.3

a = 0 or a = 1.

When a ≠ 0, the equation is quadratic and the discriminant must be zero: 16 − 16a = 0, giving a = 1. When a = 0, the equation becomes 4x + 4 = 0 and has the single root −1. Both cases are valid; do not apply the quadratic test to a linear equation. Review Example 5.06.
