Question 1

  • Guide question E1.1

If 5x − 4 = 26, what is the value of x + 2?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

8. Add 4 to get 5x = 30, so x = 6. The prompt asks for x + 2, giving 6 + 2 = 8. Substitute 6 into the original equation to verify the intermediate value, then check that your final response matches the target. Repair: Example 1.01.

Question 4

  • Guide question E1.4

A graph’s vertical axis is labeled “revenue, in thousands of dollars.” A point has vertical coordinate 2.7. What revenue, in dollars, does it represent?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

2,700 dollars. A value of 2.7 on an axis measured in thousands of dollars means 2.7(1,000) = 2,700 dollars. The scale multiplier is part of the information, not decorative labeling. A numeric test response would omit the comma and currency symbol. Repair: Example 1.08.

    Guide question E1.2

    A question’s exact answer is −114. Give two valid numeric-entry forms.

    Show model answerHide model answer for question E1.2

    For example, -11/4 or -2.75. The improper fraction −11/4 equals −2.75. Both fit the negative-response character limit and retain the minus sign. Do not enter a mixed number, an equals sign, or explanatory text in a numeric field. Repair: Example 1.03.

    Guide question E1.3

    What is the value of 24−82+6? Write a matching linear calculator entry.

    Show model answerHide model answer for question E1.3

    2; enter (24-8)/(2+6). The fraction bar groups both sums or differences. Compute the numerator 24 − 8 = 16 and denominator 2 + 6 = 8, then divide: 16/8 = 2. The matching typed expression needs parentheses around each group; the ungrouped entry is a different calculation. Repair: Example 1.06.

    Guide question E1.5

    A student gets 16 of 20 practice questions correct but cannot explain 3 of those correct answers. How many answers are secure, and how many questions belong in the review pool?

    Show model answerHide model answer for question E1.5

    13 secure answers; 7 review items. Of the 16 correct answers, 3 are not explainable, so 16 − 3 = 13 are secure. Review the 4 incorrect answers plus those 3 uncertain correct answers: 4 + 3 = 7. Raw accuracy is 16/20 = 80%, but it overstates demonstrated understanding. This result is not a score prediction. Repair: Example 1.15.

    After the exit check

    Treat any error in target, entry, or units as worth repairing immediately: those habits recur in every domain. A secure answer includes a reason, not just a matching number. Use a fresh item after reviewing; repeating a memorized answer is not a reliable retest.

    Section 1 readiness

    You should be able to identify the requested quantity, preserve grouping in calculator entry, read scaled units, enter a numeric answer correctly, and separate a guess from an explainable solution. A test-taking routine supports mathematics; it does not replace it.
