Question 1

  • Guide question M01
  • Standard

If 6(2x − 1) = 42, what is x + 3?

Why this answer

Answer: B / 7 Divide by 6: 2x − 1 = 7, so x = 4 and x + 3 = 7. The requested expression is not just x.

Linear target / Standard Review: Example 1.01.

Question 2

  • Guide question M02
  • Standard

A shop reduces a price by 15%. The sale price is $102. What was the original price?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

Answer: 120 The paid fraction is 0.85 of the original price p. Solve 0.85p = 102 to obtain p = 120.

Reverse percentages / Standard Review: Example 4.02.

Question 3

  • Guide question M03
  • Standard

The graph shows a parabola. Which expression defines it?

Why this answer

Answer: B / (x − 2)2 − 9 The vertex is (2, −9) and the curve passes through (0, −5). In a(x − 2)2 − 9, substitution gives 4a − 9 = −5, so a = 1.

Quadratic graphs / Standard Review: Example 1.07.

Question 4

  • Guide question M04
  • Standard

The equations 3x + 2y = 19 and 5x − 2y = 13 hold. What is x?

Why this answer

Answer: A / 4 Add the equations to get 8x = 32, so x = 4. Both original equations then give y = 7/2.

Linear systems / Standard Review: Example 3.01.

Question 5

  • Guide question M05
  • Standard

Two similar triangles have perimeters 21 and 35. The larger triangle has area 100. What is the area of the smaller triangle?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

Answer: 36 Perimeter scales like length, so the smaller-to-larger length factor is 21/35 = 3/5. The area is 100(3/5)2 = 36.

Similarity / Standard Review: Example 1.14.

Question 6

  • Guide question M06
  • Standard

A model is W(t) = 1200(0.64)t/2, with t in hours. Which model is equivalent?

Why this answer

Answer: D / W(t) = 1200(0.8)t For positive bases, (0.64)t/2 = (0.64)t = (0.8)t. The one-hour retention factor is 0.8.

Equivalent exponential models / Standard Review: Example 1.09.

Question 7

  • Guide question M07
  • Standard

A fitted model is yˆ = 1.5x + 8. An observed point is (10, 20). If residual is observed minus predicted, what is its residual?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

Answer: −3 The prediction is 1.5(10) + 8 = 23. Observed minus predicted is 20 − 23 = −3. The point lies below the fitted line.

Residuals / Standard Review: Example 2.09.

Question 8

  • Guide question M08
  • Standard

The equation (a − 2)x = 5 has no solution. What is a?

Why this answer

Answer: D / 2 No solution occurs when the coefficient is zero and the right side is nonzero. Thus a − 2 = 0 and a = 2, producing 0 = 5.

Parameter exceptions / Standard Review: Example 2.12.

Question 9

  • Guide question M09
  • Standard

A right triangle has hypotenuse 26 and one leg 10. What is its area?

Why this answer

Answer: C / 120 The other leg is 262 − 102 = 576 = 24. The perpendicular legs give area 12(10)(24) = 120.

Right triangles and area / Standard Review: Example 6.03.

Question 10

  • Guide question M10
  • Standard

For x ≠ 5, x2−25x−5 = 12. What is x?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

Answer: 7 Simplify to x + 5 = 12 with x ≠ 5. Thus x = 7, which is allowed. The original value is (49 − 25)/2 = 12.

Rational equations / Standard Review: Example 1.05.

Question 11

  • Guide question M11
  • Standard

A sample estimate is 47% with margin of error 3 percentage points. Which value is outside its reported interval?

Why this answer

Answer: A / 51% The interval is 44% through 50%. Therefore 51% is outside, while 44%, 47%, and 50% are within it.

Margin of error / Standard Review: Example 5.08.

Question 12

  • Guide question M12
  • Standard

The line through (1, 7) and (5, 15) has equation y = mx + b. What is m + b?

Why this answer

Answer: C / 7 The slope is (15 − 7)/(5 − 1) = 2. Using (1, 7) gives b = 5, so m + b = 7.

Lines / Standard Review: Example 1.02.

Question 13

  • Guide question M13
  • Standard

How many distinct real solutions does |x − 4| = 0 have?

Why this answer

Answer: D / 1 Absolute value is zero only when its input is zero, so x − 4 = 0 and x = 4. There are not two distinct solutions in this boundary case.

Absolute-value solution count / Standard Review: Example 3.08.

Question 14

  • Guide question M14
  • Standard

An arc of length 8π lies on a circle of radius 12. What is the central angle in degrees for that arc?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

Answer: 120 The circumference is 24π, so the arc is one-third of a circle. The angle is (1/3)(360°) = 120°.

Arcs and angles / Standard Review: Example 6.09.

Question 15

  • Guide question M15
  • Standard

In an experiment, 80 volunteers are randomly assigned to a new instructional method or a comparison method. The result supports a causal effect within the study. Which limitation remains?

Why this answer

Answer: B / The volunteers may not represent the wider student population. Random assignment supports a causal comparison within a well-conducted study. It does not make volunteers a random sample of all students, so broad generalization needs additional justification.

Statistical claims / Standard Review: Example 4.15.
