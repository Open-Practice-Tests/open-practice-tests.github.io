Question 1

  • Guide question P-A01
  • Foundation

If 7x − 9 = 40, what is x?

Why this answer

Answer: C / 7 Add 9 to get 7x = 49, then divide by 7. Substitution gives 49 − 9 = 40.

Question 2

  • Guide question P-A02
  • Foundation

The graph shows a line. What is its equation?

Why this answer

Answer: D / y = −2x + 8 The intercepts are (0, 8) and (4, 0). Thus the slope is (0 − 8)/(4 − 0) = −2 and the vertical intercept is 8.

Lines and graphs / Foundation Review: Example 1.02.

Question 3

  • Guide question P-A03
  • Standard

A line has equation 3x − 4y = 20. What is its slope?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

Answer: 3/4 Isolate y: −4y = −3x + 20, so y = (3/4)x − 5. The coefficient of x is the slope.

Linear equations in two variables / Standard Review: Example 6.01.

Question 4

  • Guide question P-A04
  • Standard

If 2x + y = 17 and x − y = 4, what is x + y?

Why this answer

Answer: D / 10 Add the equations to get 3x = 21, so x = 7. Then y = 3, and x + y = 10. Check both original equations rather than only the sum.

Systems of linear equations / Standard Review: Example 2.04.

Question 5

  • Guide question P-A05
  • Standard

For which value of k does the system 4x + 6y = 15, 2x + ky = 8 have no solution?

Why this answer

Answer: B / 3 Parallel left sides require the second coefficients to be half the first, so k = 3. The right side would need to be 7.5 for the same line, but it is 8. Thus the lines are distinct and parallel.

Solution counts / Standard Review: Example 1.03.

Question 6

  • Guide question P-A06
  • Standard

What is the greatest integer n satisfying 5n + 13 < 49?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

Answer: 7 The inequality gives 5n < 36 and n < 7.2. The greatest integer is 7. Check: 48 is less than 49, but at 8 the left side is 53.

Integer inequalities / Standard Review: Example 3.07.

Question 7

  • Guide question P-A07
  • Standard

A repair service charges $48 plus $35 per hour. A bill with no tax is $223. How many hours were charged?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

Answer: 5 With h hours, 48 + 35h = 223. Then 35h = 175 and h = 5. The fixed fee is paid once, not once per hour.

Linear modeling / Standard Review: Example 1.04.

Question 8

  • Guide question P-A08
  • Standard

For f (x) = 4x − 7, the function g is defined by g(x) = f (x + 3). What is g(2)?

Why this answer

Answer: A / 13 First compute the input to f : 2 + 3 = 5. Then f (5) = 20 − 7 = 13. The inside change is not an instruction to add 3 to the final output.

Linear functions / Standard Review: Example 5.02.

Question 9

  • Guide question P-A09
  • Standard

The equation C = 18 + rt gives cost C for time t, with t ≠ 0. Which expression equals r?

Why this answer

Answer: A / C−18t Subtract 18, then divide by nonzero t: C − 18 = rt gives r = (C − 18)/t. Keep the entire difference in the numerator.

Rearranging equations / Standard Review: Example 6.02.

Question 10

  • Guide question P-A10
  • Standard

A store sells pens for $2 and notebooks for $5. A buyer purchases 14 items for $49. How many notebooks were purchased?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

Answer: 7 Let n be notebooks and 14 − n be pens. Then 5n + 2(14 − n) = 49, so 3n = 21 and n = 7. There are also 7 pens.

Systems in context / Standard Review: Example 2.04.

Question 11

  • Guide question P-A11
  • Standard

For every real x, a(3x − 2) = 12x + b. What is a + b?

Why this answer

Answer: B / −4 Equality for every x requires matching coefficients: 3a = 12, so a = 4. The constant is b = −2a = −8. Thus a + b = −4.

Identities and constants / Standard Review: Example 1.03.

Question 12

  • Guide question P-A12
  • Challenge

The line through (3, −2) is perpendicular to y = 32 x + 7. What is its y-intercept?

Enter an integer, decimal or fraction without units. Use up to 5 characters, or 6 including a leading minus.

Why this answer

Answer: 0 The perpendicular slope is −2/3. Write y = (−2/3)x + b and substitute (3, −2): −2 = −2 + b, so b = 0.

Perpendicular lines / Challenge Review: Example 6.01.
